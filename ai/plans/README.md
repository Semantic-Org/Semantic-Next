# Plans

Implementation plans for Semantic UI Next. The master roadmap is [`ROADMAP.md`](ROADMAP.md) — start there for what's being built, in what order, and what's blocked on what.

## Folder structure

| Folder | Meaning |
|---|---|
| `ai/plans/*.md` (top-level) | On the roadmap. Has a phase, position, momentum — not yet in flight. |
| [`active/`](active/README.md) | In flight — open PR or live pair work. Mirrored on ROADMAP's `## Currently Open`. |
| [`icebox/`](icebox/README.md) | Drafted but not on the active roadmap. |
| `archive/` | Completed or rejected plans. The catalog of shipped work. |

A plan moves between folders as its lifecycle state changes. Phases are narrative-only — they live in `ROADMAP.md`, not as folders.
