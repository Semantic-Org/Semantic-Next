# AI Trash

Archive for AI-generated artifacts that are no longer actively needed. Files are kept here for historical reference rather than deleted outright. Structure mirrors `ai/workspace/` where applicable.

## Contents

- **plans/** — Completed or superseded plans from `ai/workspace/plans/`
- **investigations/** — Finished challenge/investigation deep-dives
- **evaluations/** — Completed evaluation reports and verification outputs
- **artifacts/** — Expired research outputs, CSVs, one-off HTML files
- **memory/** — Legacy workspace memory files (predates auto-memory system)
- **scripts/** — One-off utility scripts from completed tasks
- **misc/** — Uncategorized files from past sessions
