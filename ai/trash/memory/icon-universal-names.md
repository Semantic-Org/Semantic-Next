## Notes for Implementation

1. **Icon Name vs Universal Term**: When the icon name differs significantly from its universal meaning, prefer the universal term in code comments and component naming.

2. **Multiple Meanings**: Some icons serve multiple purposes (e.g., `x` for close/remove/cancel). Context determines which meaning applies.

3. **Consistency**: Within a single application, use the same icon for the same action throughout.

4. **Accessibility**: Always pair icons with appropriate aria-labels using the universal terms.

5. **State Variants**: Many icons have state pairs (toggle/toggle-off, checkbox/checkbox-empty, eye/eye-slash). Always implement both states.

6. **Form Controls**: Use semantic form control icons (radio, checkbox, toggle) consistently to match platform conventions.

7. **Brand Icons**: Brand logos should link to their respective platforms and follow brand guidelines for usage.
