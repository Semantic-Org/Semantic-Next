# Icon Gaps - Suggested Additions

Icons not currently in the canonical spec that an AI agent would commonly reach for when generating standard app templates.

## High Priority

| Name | Category | Rationale |
|---|---|---|
| `minus` | action | Paired with `add`/plus for increment/decrement, collapsing sections |
| `arrow-right` | navigation | Distinct from chevrons, used in wizards and flow indicators |
| `arrow-left` | navigation | Distinct from chevrons, used in wizards and flow indicators |
| `arrow-up` | navigation | Distinct from chevrons, used in data movement |
| `arrow-down` | navigation | Distinct from chevrons, used in data movement |
| `hash` | misc | Channels, tags, numbering |
| `message` | communication | Distinct from `comment`, for messaging/chat UIs |
| `scan` | action | QR scanning, document scanning |
| `translate` | system | i18n is ubiquitous |
| `palette` | editing | Theme/color customization |
| `rocket` | misc | Onboarding, launch, getting started |
| `crown` | gamification | Premium/pro tier indicators |
| `percent` | data | Statistics, discounts |
| `notification-off` | communication | Mute notifications (we have `mute` for audio but not notifications) |
| `restore` | action | Undo archive/delete, distinct from `undo` |

## Medium Priority

| Name | Category | Rationale |
|---|---|---|
| `maximize` | navigation | Window/panel controls (different from fullscreen) |
| `minimize` | navigation | Window/panel controls (different from fullscreen) |
| `badge` | status | Notification indicators, status dots |
| `dot` | status | Inline status indicators |
| `circle-check` | status | Success state inside circle, distinct from bare `check` |
| `circle-x` | status | Error state inside circle |
| `dollar` | finance | Explicit currency symbol (`money` exists but `dollar` is instinctive) |
| `signal` | connectivity | Connection strength |
