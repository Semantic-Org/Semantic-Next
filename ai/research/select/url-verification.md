## Component Naming Variations
Different frameworks use different names:
- **Select** - Most common name (8 frameworks)
- **Dropdown** - PrimeReact, Semantic UI
- **Listbox** - Headless UI (more semantic HTML name)
- **Combobox** - Related component (Mantine also has separate Combobox)
