# Classic SUI Divider Variables

## Margin & Spacing
- Base margin: `1rem 0rem`
- Horizontal divider margin: `1em`
- Vertical divider margin: `1rem`
- Section margin: `2rem`

## Colors
- Text color: dark text color
- Highlight: `1px` white border
- Shadow: `1px` border color
- Inverted text: white
- Inverted highlight: `rgba(255, 255, 255, 0.15)`

## Typography
- Letter spacing: `0.05em`
- Font weight: `bold`
- Text transform: `uppercase`

## Icon
- Icon size: `1rem`
- Icon margin: `0rem`

## Approach
- Horizontal uses `display: table` with `:before/:after` for lines
- Text interrupts the line naturally
- Vertical uses absolute positioning
