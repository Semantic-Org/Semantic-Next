# UI Components List - Classic Semantic UI

Complete alphabetical list of all UI components from classic Semantic UI (version 2.x).

## Elements

* **Button** - A button indicates a possible user action
* **Container** - A container limits content to a maximum width
* **Divider** - A divider visually segments content into groups
* **Flag** - A flag represents a country or region
* **Header** - A header provides a short summary of content
* **Icon** - An icon is a glyph used to represent something else
* **Image** - An image is a graphic representation of something
* **Input** - An input is a field used to elicit a response from a user
* **Label** - A label displays content classification
* **List** - A list groups related content
* **Loader** - A loader alerts a user to wait for an activity to complete
* **Placeholder** - A placeholder is used to reserve space for content that soon will appear in a layout
* **Rail** - A rail is used to show accompanying content outside the boundaries of the main view of a site
* **Reveal** - A reveal displays additional content in place of previous content when activated
* **Segment** - A segment is used to create a grouping of related content
* **Step** - A step shows the progression through a series of activities

## Collections

* **Breadcrumb** - A breadcrumb is used to show hierarchy between content
* **Form** - A form displays a set of related user input fields in a structured way
* **Grid** - A grid is used to harmonize negative space in a layout
* **Menu** - A menu displays grouped navigation actions
* **Message** - A message displays information that explains nearby content
* **Table** - A table displays collections of data grouped into rows

## Views

* **Advertisement** - An ad displays promotional content in standard ad unit sizes
* **Card** - A card displays site content in a manner similar to a playing card
* **Comment** - A comment displays user feedback to site content
* **Feed** - A feed presents user activity chronologically
* **Item** - An item displays site content for listings and directories
* **Statistic** - A statistic emphasizes the current value of an attribute

## Modules

* **Accordion** - An accordion allows users to toggle the display of sections of content
* **Checkbox** - A checkbox allows a user to select a value from a small set of options
* **Dimmer** - A dimmer hides distractions to focus attention on particular content
* **Dropdown** - A dropdown allows a user to select a value from a series of options
* **Embed** - An embed displays content from other websites like YouTube videos or Google Maps
* **Modal** - A modal displays content that temporarily blocks interactions with the main view of a site
* **Popup** - A popup displays additional information on top of a page
* **Progress Bar** - A progress bar shows the progression of a task
* **Rating** - A rating indicates user interest in content
* **Search** - A search module allows a user to query for results from a selection of data
* **Shape** - A shape displays content that can be rotated or flipped in 3D
* **Sidebar** - A sidebar hides additional content beside a page
* **Sticky** - Sticky content fixes itself to the browser viewport as content is scrolled
* **Tab** - A tab is a hidden section of content activated by a menu
* **Transition** - A transition animates changes to an element
