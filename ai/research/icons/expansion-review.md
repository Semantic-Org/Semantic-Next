## REJECTED (409 icons)

### Synonym / Better Glyph Already Chosen (key examples)
- `cog` → settings already chosen
- `settings-2` → settings already chosen
- `trash` → trash-2 is better glyph
- `redo` → redo-2 is better glyph
- `maximize` → maximize-2 is better glyph
- `building` → building-2 is better glyph
- `user-round` → user already chosen
- `key` → key-round already chosen
- `laptop` → laptop-minimal is better glyph
- `tv` → tv-minimal is better glyph

### Container Variants of Standalone Icons
- `circle-chevron-*` → chevron-* exists standalone
- `square-check-big`, `square-play`, `square-plus`, `square-minus`, `square-x` → circle-* variants already chosen
- `square-pen`, `square-code`, `square-terminal`, `square-user` → base icons exist
- `circle-user-round` → circle-user already chosen

### Compositional (action + base icon = these)
- `archive-x`, `copy-minus/plus/x`, `funnel-plus/x`, `mail-check/minus/warning/x`
- `bookmark-minus/x`, `calendar-minus/off`, `image-down/minus/up`
- `folder-check/down/minus/output/search/sync/up/x`
- `monitor-check/cog/off`, `package-minus/plus/x`
- `heart-crack/handshake/minus/off/plus`, `shield-ban/off/plus`

### Too Niche for Agent Hit Rate
- Objects: `atom`, `bolt`, `diamond`, `disc`, `hexagon`, `magnet`, `mountain`, `octagon`, `orbit`, `skull`, `umbrella`, `vault`, `warehouse`, `weight`
- Hardware: `cable`, `microchip`, `mouse`, `nfc`, `router`, `usb`, `webcam`
- Redundant arrows: `arrow-big-*`, `arrow-*-from/to-line/dot`, `arrow-*-wide-narrow`
- Signal/wifi levels: `signal-high/low/medium/zero`, `wifi-high/low/zero`
- Duplicate families: `user-round-*` duplicating `user-*`
- Brand logos: `gitlab`, `instagram`, `linkedin`
- Niche features: `closed-caption` (use captions), `lasso-select`, `picture-in-picture`, `proportions`
