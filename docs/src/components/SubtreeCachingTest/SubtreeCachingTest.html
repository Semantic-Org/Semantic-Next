Async & Rerender

1. Async inside Rerender

Click to toggle darkMode. Message should update without flashing empty. Loading only on initial load.

{#rerender darkMode} {#async formatMessage as msg} {msg} {loading} loading... {/async} {/rerender}

2. Async Stale Promise

Click once to trigger 3 rapid fetches (v1, v2, v3 at 100ms intervals, 500ms each). Only "Result v3" should appear.

{#async fetchWithDelay as result} {result} {/async}

3. Computed Value in Rerender

Click to change label and increment counter. The computed string should reflect both changes immediately.

{#rerender counter} {getComputedLabel} {/rerender}

4. Nested Rerender (Same Key)

Two rerender blocks nested, both keyed on same signal. Both label and timestamp should update on each click.

{#rerender depthSignal} Outer: {getDepthLabel} {#rerender depthSignal} Inner: {getTimestamp} {/rerender} {/rerender}

Each Loops

5. Each with Filter Toggle

Toggle between all 4 items and only active items (Alpha, Gamma). List should update with no stale entries.

{#each item in getFilteredItems}
{item.name} {item.value}
{else}
No items
{/each}

6. Each with Duplicate Primitive Values

Renders [1,1,2,2,3] — duplicate values test key degeneracy. Click to multiply by 10. All 5 items should show distinct indices.

{#each val, i in getDuplicates} [{i}] {val} {/each}

7. Each Empty/Populated Transition

Toggles between populated list and else branch. Should alternate cleanly between "No items" and fruit names.

{#each item in getToggleableList} {item.text} {else} No items yet {/each}

8. Conditional inside Each

Toggle active state on all items. Checkmarks and crosses should swap. If stale, symbols won't change.

{#each item in getToggleItems}
{#if item.active} ✓ {item.name} {else} ✗ {item.name} {/if}
{/each}

9. External Signal Controls Conditionals in Each

Items have thresholds 1/2/3. Bump cycles 0→1→2→3→0. At 0: all wait. At 3: all active. Signal is external to each data.

Level: {globalThreshold} {#each item in thresholdItems}
{item.name} {#if isAboveThreshold item.threshold} active {else} waiting {/if}
{/each}

Nested Structures

10. Nested Each with Highlights

Cycle search: none → "se" → "set" → none. Items should filter and bold-highlight correctly. No stale highlights on return.

{#each group in getGroups}
{group.name} {#each entry in group.entries}
{>entryDisplay entry=entry}
{/each}
{/each}

11. Three-Level Nesting (Rerender / Each / If)

Rerender wraps each, each wraps if. "Bump" forces outer rerender. "Flip" inverts visible/hidden. Both should work independently.

{#rerender layerKey} {#each item in getLayeredItems}
{item.name} {item.tier} {#if item.show} visible {else} hidden {/if}
{/each} {/rerender}

Snippets

12. Snippet Called Per Item

Each badge should show different name and color. If snippets collide, all badges show same text/color.

{#each item in items} {>badge label=item.name color=item.color} {/each}

13. Nested Snippet Invocations

Outer snippet calls inner snippet. Two instances with swapped data. Instance 1: "hello → world", Instance 2: "world → hello". Swap button reverses both.

1: {>wrapSnippet outer=getOuterText inner=getInnerText} 2: {>wrapSnippet outer=getInnerText inner=getOuterText}

Async in Loops

14. Async Per-Item in Each

Three items with different delays (100/250/400ms). Each resolves independently. "Bump Version" should trigger fresh resolution with new labels.

{#each item in getAsyncItems}
{item.label}: {#async resolveItem item as result} {result} {loading} resolving... {/async}
{/each}

Special Cases

15. Guard Block: Equivalent Outputs

Cycles low→medium→high. "low" and "medium" both map to "basic". Guard should NOT re-render on low→medium but SHOULD on medium→high.

Input: {guardInput} {#guard getGuardCategory} Category: {getGuardCategory} {/guard}

Non-Reactive Data Propagation

15a. Non-reactive Expressions in Each

Click to change item status from "pending" to "done". Plain object properties (no signals) must update in cached each subtrees.

{#each item in getNonReactiveItems} {item.name}:{item.status} {/each}

15b. Non-reactive Conditionals in Each

Click to flip visibility. Conditional branches should swap based on plain data, not signals.

{#each item in getNonReactiveCondItems} {#if item.visible}SHOW:{item.name}{else}HIDE:{item.name}{/if} {/each}

15c. Non-reactive Snippet Data in Each

Click to change tags. Snippet content should reflect new plain data values.

{#each item in getNonReactiveSnippetItems} {>tagSnippet label=item.tag} {/each}

15d. Non-reactive Data in Rerender

Click to change label and bump counter. The computed string should reflect both changes immediately.

{#rerender rerenderTick} {getRerenderLabel} {/rerender}

Attribute & Reorder

13b. Attribute-driven Async

Click to change the label setting via attribute. Async should preserve old content while re-resolving, then show new value.

{#async formatAttrLabel as result} {result} {loading} loading... {/async}

14. Each Item Reorder

Click to reverse item order. Colors must stay with their names. If cached subtrees swap incorrectly, Alpha might show green.

{#each item in getOrderedItems} {item.name}:{item.color} {/each}

16. SVG and HTML with Shared Data

SVG each-loop renders circles, HTML each-loop renders text from same data. Scaling one should not affect the other.
