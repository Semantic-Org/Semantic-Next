## Overview

Semantic UI templates provide a declarative syntax for generating the HTML structure of your [Web Components](/introduction). They integrate features like [looping](/templates/loops), [conditionals](/templates/conditionals), [expressions](/templates/expressions), and access to a component's [data context](/components/rendering#data-context) to simplify rendering dynamic views.

## Template Syntax

Templates all support either single or double bracket syntax and are whitespace insensitive. Use what style you and your team prefer.

#### Single Bracket
```sui
Welcome, { getFirstName }
```

#### Double Bracket
```sui
Welcome, {{ getFirstName }}
```

> **Flexible Dialects:** Templates support both `{ expression }` and `{{ expression }}` syntax, chosen for developer preference (e.g., familiarity from JSX/Svelte vs. Handlebars/Rails). Both compile identically and efficiently.

### Template Compilation and Usage

Semantic UI templates compile to an Abstract Syntax Tree (AST). This AST is used to efficiently render the component's [Shadow DOM](https://developer.mozilla.org/en-US/docs/Web/API/Web_components/Using_shadow_DOM) and perform targeted updates only when underlying [reactive data sources](/reactivity) change.

> See the [Templates & Data Context](/components/rendering) guide for details on how templates integrate with component data.

## Template Features

### [Expressions](/templates/expressions)

Allow values to be output and functions executed from the template's [data context](/components/rendering#data-context).

#### Value Output
```sui
{name}
```

#### Function Calls
```sui
{someMethod argumentOne argumentTwo}
```

#### Complex Nested Expressions
```sui
{formatDateTime someDate 'YYYY-MM-DD HH:mm' (object timezone='local')}
```

#### Nested expressions
```sui
{formatDate (getDate now) 'h:mm a'}
```

#### HTML Output
```sui
{#html someHTML}
```

### [Conditionals](/templates/conditionals)

Control flow using `#if`, `#else if`, and `#else`.
```sui
{#if isColor 'red'}
  Red
{else if isColor 'blue'}
  Blue
{else}
  Another color
{/if}
```

### [Loops](/templates/loops)

Iterate over collections using `#each`.
```sui
{#each row in someCollection}
  {row.name}
{/each}
```

With inner data context
```sui
{#each someCollection}
  {name}
{/each}
```

With array index
```sui
{#each someCollection}
  {index}
{/each}
```

With else
```sui
{#each someCollection}
  {index}
{else}
  No value
{/each}
```

### [Slots](/templates/slots)

Define areas for external content injection.

Default Slot
```sui
{>slot}
```
Named Slot
```sui
{>slot icon}
```

### [Global Helpers](/templates/helpers)

Access built-in utility functions for common tasks like formatting or logic.
```sui
{stringify someObject}
{formatDate someDate}
{log 'Hello World'}
```

### [Subtemplates](/templates/subtemplates)

Compose components by rendering other component templates.

Named Templates
```sui
{> exampleSubtemplate}
```
Dynamic Template Support
```sui
{>template
  name=getTemplateName
  data={
    afternoon: 'Biking',
    evening: getEveningActivity,
  }
}
```

Reactive Data Controls
```sui
{>template
  name=getTemplateName
  reactiveData={
    morning: morningActivity,
  }
  data={
    afternoon: 'Biking',
    evening: eveningActivity,
  }
}
```

### [Snippets](/templates/snippets)

Define and reuse inline template fragments within the same file.

```sui
{#snippet fullName}
  {#if both firstName lastName}
    {firstName} {lastName}
  {else}
    {lastName}
  {/if}
{/snippet}

{#if isLoggedOut}
  Login, {>fullName}
{else if hasName}
  Login, {>fullName}
{else}
  Login
{/if}
```
