Semantic UI's first party component framework includes many of the common UI components that are essential building blocks of a website. These can be used inside your own custom components to build [more complex components](/examples/card-search) or simply anywhere you use html.

> **Note on Technical Preview** Semantic UI is in technical preview, the primary focus has been on authoring the [component framework](/components) which UI components will be written. It is recommended if you are looking to use Semantic UI primarily as a UI framework to check back later in 2025 for more robust components.

## Set up Guide

<Tabs>
  <TabItem label="Javascript">

  1. **Install the package** using a package manager:

      <Tabs>
        <TabItem label="NPM">
          ```bash
          npm install @semantic-ui/core
          ```
        </TabItem>
        <TabItem label="PNPM">
          ```bash
          pnpm install @semantic-ui/core
          ```
        </TabItem>
        <TabItem label="Yarn">
          ```bash
          yarn add @semantic-ui/core
          ```
        </TabItem>
      </Tabs>

  2.  **Import the javascript and css** from each component you would like to include once globally

      ```javascript
      import '@semantic-ui/core/components/button';
      import '@semantic-ui/core/themes/button.css';
      ```

  3. **Use the web component** anywhere in your html:

      ```html
      <ui-button primary>Click me</ui-button>
      ```

  </TabItem>
  <TabItem label="Browser">

  1. Import each components using `<script>` tag in your `<head>`

      <Tabs>
        <TabItem label="SUI">
          ```html
         <head>
            <script src="https://cdn.semantic-ui.com/@semantic-ui/core/0.10.9/dist/ui/components/button.js"></script>
            <script src="https://cdn.semantic-ui.com/@semantic-ui/core/0.10.9/dist/ui/components/input.js"></script>
         </head>
         ```
        </TabItem>
        <TabItem label="JSDelivr">
          ```bash
          pnpm install @semantic-ui/core
          ```
        </TabItem>
        <TabItem label="Unpkg">
          ```bash
          yarn add @semantic-ui/core
          ```
        </TabItem>
      </Tabs>

  2. Import the javascript and css from each component you would like to include once anywhere on the client

      ```javascript
      import '@semantic-ui/core/components/button';
      import '@semantic-ui/core/themes/button.css';
      ```

  3. You can now use that component in your html:

      ```html
      <ui-button primary>Click me</ui-button>
      ```
    ```html title="index.html"
    <html>
    <head>
      <link rel="stylesheet" href="https://unpkg.com/@semantic-ui/core/dist/themes/button.css">
      <script type="module" src="https://unpkg.com/@semantic-ui/core/components/button"></script>
    </head>
    <body>
      <ui-button primary>Click me</ui-button>
    </body>
    </html>
    ```
  </TabItem>
</Tabs>
