Semantic UI's first party component framework includes many of the common UI components that are essential building blocks of a website. These can be used inside your own custom components to build [more complex components](/examples/card-search) or simply anywhere you use html.

> **Note on Technical Preview** Semantic UI is currently under heavy active development. The [component framework](/components) will be  **fully available Q2 2025**, and subsequently UI components will be **completed throughout 2025 and 2026**. It is recommended if you are looking to use Semantic UI primarily as a UI framework to check back later in 2025 for additional components.

## Set up Guide

<Tabs>
  <TabItem label="Javascript">

  1. **Install the package** using a package manager:

      <Tabs>
        <TabItem label="NPM">
          ```bash
          npm install @semantic-ui/core
          ```
        </TabItem>
        <TabItem label="PNPM">
          ```bash
          pnpm install @semantic-ui/core
          ```
        </TabItem>
        <TabItem label="Yarn">
          ```bash
          yarn add @semantic-ui/core
          ```
        </TabItem>
      </Tabs>

  2.  **Import the global theme** to define global variables used across components

      ```javascript
      import '@semantic-ui/core/themes/base.css';
      ```

  3.  **Import the UI Components**

      *Option 1* - Import only the components you would like to use.

      ```javascript
      import '@semantic-ui/core/button';
      import '@semantic-ui/core/themes/button.css';
      ```

      *Option 2* - Import the entire framework to access every component.

      ```javascript
      import '@semantic-ui/semantic-ui.js';
      import '@semantic-ui/semantic-ui.css';
      ```

  4. **Use UI components** wherever you write html:

      ```html
      <ui-button primary>Click me</ui-button>
      ```

  </TabItem>
  <TabItem label="Browser">


  2.  **Import the global theme** to define global variables used across components

          ```html
         <head>
            <link href="https://cdn.semantic-ui.com/@semantic-ui/core/0.10.9/dist/theme/base.css" rel="stylesheet" />
         </head>
         ```

  3.  **Import the UI Components**

      *Option 1* - Import only the components you would like to use.

      ```javascript
         <head>
          <script src="https://cdn.semantic-ui.com/@semantic-ui/core/0.10.9/dist/ui/components/button.js"></script>
          <script src="https://cdn.semantic-ui.com/@semantic-ui/core/0.10.9/dist/themes/button.css"></script>
        </head>
      ```

      *Option 2* - Import the entire framework to access every component.

        ```html
       <head>
        <script src="https://cdn.semantic-ui.com/@semantic-ui/core/0.10.9/dist/semantic-ui.css"></script>
        <script src="https://cdn.semantic-ui.com/@semantic-ui/core/0.10.9/dist/semantic-ui.js"></script>
       </head>
       ```

  4. **Use UI components** wherever you write html:

      ```html
      <ui-button primary>Click me</ui-button>
      ```

  </TabItem>
