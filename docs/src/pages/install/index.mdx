Semantic UI's first party component framework includes many of the common UI components that are essential building blocks of a website. These can be used inside your own custom components to build [more complex components](/examples/card-search) or simply anywhere you use html.

> **Note on Technical Preview** Semantic UI is currently under heavy active development. The [component framework](/components) will be  **fully available Q2 2025**, and subsequently UI components will be **completed throughout 2025 and 2026**. It is recommended if you are looking to use Semantic UI primarily as a UI framework to check back later in 2025 for additional components.

## Set up Guide

<Tabs>
  <TabItem label="Javascript">

  1. **Install the package** using a package manager:

      <Tabs>
        <TabItem label="NPM">
          ```bash
          npm install @semantic-ui/core
          ```
        </TabItem>
        <TabItem label="PNPM">
          ```bash
          pnpm install @semantic-ui/core
          ```
        </TabItem>
        <TabItem label="Yarn">
          ```bash
          yarn add @semantic-ui/core
          ```
        </TabItem>
      </Tabs>

  2.  **Import the global CSS** to define design tokens required by components

      ```javascript
      import '@semantic-ui/core/css';
      ```

  3.  **Import Specific UI Components** - CSS is automatically included in each component's Shadow DOM

      *Option 1* - Import the components you would like to use.

      ```javascript
      import { UIButton } from '@semantic-ui/core';
      ```

      Or use the export condition without importing the component.
      ```javascript
      import '@semantic-ui/core/button';
      ```

      *Import All* - Import the entire framework to access every component.

      ```javascript
      import '@semantic-ui/core';
      ```

  4. **Use UI components** wherever you write html:

      ```html
      <ui-button primary>Click me</ui-button>
      ```

  </TabItem>
