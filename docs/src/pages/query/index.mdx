## Introduction

Query is a library built to make it easy to interact with a page's DOM and shadow DOM in a chainable way. Query was custom built to make it easy to handle web components and access their inner DOM trees using a single jQuery-like syntax.

Query includes many helpers which make it easy to interact with web components, emit and consume events, traverse the DOM tree, retrieve common values and much more - all in a tiny 3kb package!

> **API Reference** For a comprehensive explanation of all functions, visit the [API reference guide](/api/query).

### Why Create a Library

Web components are built around encapsulating portions of the DOM in the Shadow DOM, which prevent easy access or reference from other scopes.

Many common usage patterns for developers require traversing the DOM, but with native APIs these will stop at shadow DOM root or slotted content boundaries. Doing this deeply or recursively is basically impossible without writing your own helpers.

Query gives you all the utilities like [`closest`](/api/query/dom-traversal#closest), [`find`](/api/query/dom-traversal#find), [`siblings`](/api/query/dom-traversal#siblings) across multiple web components or shadow DOM boundaries.

## Getting Started with Query

Query provides a familiar, jQuery-like API for working with the DOM. The core function `$()` lets you select elements and perform operations on them using a chainable interface.

### Installation

```bash
npm install @semantic-ui/query
```

### Import and Usage

```javascript
import { $ } from '@semantic-ui/query';

// Select elements
const divs = $('div');

// Chain operations
$('.content')
  .addClass('active')
  .css('color', 'blue')
  .on('click', function() {
    $(this).removeClass('active');
  });
```

## Core Concepts

Query provides two main functions:

- **[$](/query/basics)** - For querying the standard DOM tree
- **[$$](/query/shadow-dom)** - For querying across shadow DOM boundaries

This provides you with the right tool for different scenarios.

> **Performance** The `$` function uses the standard DOM APIs directly, making it faster for regular DOM queries. The `$$` function traverses shadow DOM boundaries recursively, which requires more processing. When you don't need to access shadow DOM content, using `$` will be more efficient.

```javascript
import { $, $$ } from '@semantic-ui/query';

// Standard DOM query
const regularDivs = $('div');

// Shadow DOM query
const shadowDivs = $$('ui-button div');
```

Query uses the concept of [chaining](/query/chaining), where method calls can be connected in sequence for more concise code.

## Integration with Components

Query is integrated into the Semantic UI component system. Both `$` and `$$` are available in all [component lifecycle callbacks](/components/lifecycle).

```javascript
const createComponent = ({ $, $$ }) => ({
  initialize() {
    $('div').addClass('initialized');

    // Access elements deep in shadow DOM
    const nestedElements = $$('.nested-content');
  }
});
```

> Learn more about using Query with components in the [Components integration guide](/query/components).
