## Seamless Integration

Query is deeply woven into the fabric of Semantic UI components, giving you powerful DOM manipulation capabilities at every stage of the component lifecycle. This integration eliminates the need for manual DOM querying and simplifies common component operations.

## Automatic Query Access

When building Semantic UI components, you don't need to import or initialize Query — it's automatically available throughout your component code:

```javascript
// No imports needed - Query is injected automatically
const createComponent = ({ $, $$ }) => ({
  initialize() {
    // Start using Query right away
    $('.content').addClass('initialized');
    
    // Access elements across shadow DOM boundaries
    $$('ui-button .label').text('Ready');
  }
});
```

This automatic injection reduces boilerplate and ensures consistent access to DOM utilities throughout your components.

## Component Lifecycle Integration

Query is available at every stage of a component's lifecycle, enabling you to handle DOM manipulation exactly when you need it.

### Initialization Phase

Set up your component when it's first created:

```javascript
const createComponent = ({ $, $$ }) => ({
  initialize() {
    // Initialize component state
    $('.tabs').each((index, tab) => {
      $(tab).data('tab-index', index);
    });
    
    // Set initial state
    $('.tab:first-child').addClass('active');
    $('.tab-content:first-child').show();
  }
});
```

### Creation Phase

Handle elements before they're connected to the DOM:

```javascript
const onCreated = ({ $, $$ }) => {
  // Prepare component before it's visible
  $('input').prop('disabled', true);
  $('.placeholder').show();
};
```

### Rendering Phase

Manipulate the DOM after rendering is complete:

```javascript
const onRendered = ({ $, $$, isClient }) => {
  // Only run DOM manipulation in browser environments
  if (isClient) {
    // Initialize animations after rendering
    $('.fade-in').addClass('visible');
    
    // Measure and position elements
    const height = $('.content').height();
    $('.sidebar').css('min-height', `${height}px`);
  }
};
```

### Event Handling

Query is also available in all event handlers:

```javascript
const events = {
  'click .tab'({ $, $$, target }) {
    // Deactivate all tabs
    $('.tab').removeClass('active');
    
    // Activate clicked tab
    $(target).addClass('active');
    
    // Show corresponding content
    const index = $(target).data('tab-index');
    $('.tab-content').hide();
    $(`.tab-content[data-index="${index}"]`).show();
  }
};
```

## $ vs $$ in Components

Within components, you have access to both Query functions, each with a specific purpose:

```javascript
const createComponent = ({ $, $$ }) => ({
  initialize() {
    // $ queries within this component's shadow DOM
    $('.content').addClass('initialized');
    
    // $$ can reach outside this component or into nested components
    $$('ui-button').on('click', function() {
      console.log('Button clicked');
    });
  }
});
```

### Best Practices for $ vs $$

Choose the right tool for your use case:

1. **Use `$` for internal component elements**
   - More efficient when you're working within your component's shadow DOM
   - Use for most component operations that don't cross boundaries

   ```javascript
   $('.tab').on('click', this.handleTabClick);
   ```

2. **Use `$$` when crossing component boundaries**
   - When accessing nested components
   - When reaching out to parent or sibling components
   - When you're unsure about the DOM structure

   ```javascript
   $$('ui-menu .item').each((i, item) => {
     // Work with all menu items, wherever they are
   });
   ```

## Interacting with External Components

Query provides special methods for working with components from the outside, bridging the gap between components and the DOM.

### Accessing Component Instances

The `getComponent()` method gives you direct access to a component's API:

```javascript
// Get a reference to the button component
const button = $('ui-button.primary').getComponent();

// Now you can call its methods directly
if (button) {
  // Access the underlying component instance
  console.log('Button is disabled:', button.isDisabled());
  
  // Update settings
  button.settings.icon = 'arrow-right';
}
```

This approach lets you integrate with component APIs while maintaining a clean separation of concerns.

### Component Configuration

Query provides two main methods for configuring components:

#### settings()

Configure existing components immediately:

```javascript
// Configure all buttons on the page
$('ui-button').settings({
  icon: 'arrow-right',
  primary: true,
  state: 'active'
});
```

#### initialize()

Pre-configure components before they exist:

```javascript
// Set up configuration that will apply to future components
$('ui-modal').initialize({
  icon: 'close',
  closable: true,
  state: 'active',
  onRendered: (modal) => {
    console.log('Modal rendered:', modal);
  }
});
```

This approach lets you implement configuration patterns like:

```javascript
// Configure all components at once
$('ui-button').initialize({ icon: 'checkmark' });
$('ui-menu').initialize({ vertical: true });
$('ui-modal').initialize({ closable: true });
```

## Advanced Component Examples

### Managing Component State

```javascript
// Component definition
const createComponent = ({ $, $$, state }) => ({
  initialize() {
    // Set up using the initial state
    this.activateTab(state.activeTab.value);
  },
  
  // Component methods can use Query too
  activateTab(index) {
    // Update state
    state.activeTab.set(index);
    
    // Update UI
    $('.tab').removeClass('active');
    $(`.tab[data-index="${index}"]`).addClass('active');
    
    // Show correct content
    $('.content').removeClass('visible');
    $(`.content[data-index="${index}"]`).addClass('visible');
  }
});

// Define component with state
defineComponent({
  tagName: 'ui-tabs',
  template: '...template code...',
  defaultState: {
    activeTab: 0
  },
  createComponent,
  // Event handlers for tab clicks
  events: {
    'click .tab'({ $, state, self, target }) {
      const index = $(target).data('index');
      self.activateTab(index);
    }
  }
});
```

### Using Event Handlers

```javascript
const events = {
  'click .tab'({ $, target }) {
    // Get tab index from data attribute
    const index = $(target).data('index');
    
    // Update active tab
    $('.tab').removeClass('active');
    $(target).addClass('active');
    
    // Show corresponding content
    $('.content').hide();
    $(`.content[data-index="${index}"]`).show();
  }
};
```
