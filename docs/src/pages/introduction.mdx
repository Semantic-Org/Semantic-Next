Semantic UI is a framework for authoring **standard W3C [Web Components](https://developer.mozilla.org/en-US/docs/Web/API/Web_components)**. Components work natively in modern browsers and integrate with frameworks like [React](https://react.dev/), [Vue](https://vuejs.org/), and [Angular](https://angular.io/).

### Design System vs Framework

* Semantic UI provides a **[first-party design system](/usage)** to handle common primitives like [buttons](/ui/button), [menus](/ui/menu), and [inputs](/ui/input) that can be used anywhere you write html.

* Semantic UI provides **[tools for authoring custom UI components](/components)**. Write your own design system, or create open source UI components to share with others.

> To see examples of custom components check out our [examples gallery](/examples/advanced-ball-simulation).

### Key Features

*   [Signals-based reactivity](/reactivity) for state management.
*   [Declarative templating](/templates) for rendering component views.
*   [DOM querying](/query) tailored for [Shadow DOM](https://developer.mozilla.org/en-US/docs/Web/API/Web_components/Using_shadow_DOM) encapsulation.
*   CSS token framework for [dark/light mode styling and theming](/components/styling).
*   Integrated [event handling](/components/events) tools.
*   Declarative [keybinding management](/components/keys).
