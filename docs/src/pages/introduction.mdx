The two main ways to use Semantic UI
* **Design with UI Components** - Semantic provides a [UI component library](/ui) with [buttons](/ui/button), [menus](/ui/menu), [inputs](/ui/input) and other essential components. These components are distributes as web components meaning they can be used anywhere on the web.
* **Author with the Web Component Framework** - Semantic provides a [component framework](/components) to create custom reactive UI with web components that can be used anywhere you use html.

> Semantic UI's component framework is designed to provide the missing toolkit to make web components easy to author and ship at scale, with features like [reactivity](/reactivity), [templating](/templates), tools for [events](/components/events) and [keybindings](/components/keys), and a robust [css framework](/components/styling) for styling.
