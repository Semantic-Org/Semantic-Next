Semantic UI is a framework for authoring **standard W3C [Web Components](https://developer.mozilla.org/en-US/docs/Web/API/Web_components)** that work natively in modern browsers, integrate readily with frameworks like [React](https://react.dev/), [Vue](https://vuejs.org/), [Angular](https://angular.io/), or others supporting Web Components, and offer long-term maintainability with reduced framework lock-in.

### Two Ways To Use

* Semantic UI includes **first-party UI components** to handle common primitives like [buttons](/ui/button), [menus](/ui/menu), and [inputs](/ui/input) provided by [`@semantic-ui/core`](/usage) that can be used anywhere you write html.

* Semantic UI provides a **tools for authoring custom web components**, with our [component authoring framework](/components). Write your own design system, or create open source UI components to share with others.

> To see examples of custom components check out our [examples gallery](/examples/advanced-ball-simulation).

### Key Add-ons to Web Components

*   [Signals-based reactivity](/reactivity) for state management.
*   [Declarative templating](/templates) for rendering component views.
*   [DOM querying](/query) tailored for [Shadow DOM](https://developer.mozilla.org/en-US/docs/Web/API/Web_components/Using_shadow_DOM) encapsulation.
*   Robust CSS token framework for [dark/light mode styling and theming](/components/styling).
*   Integrated [event handling](/components/events) tools.
*   Declarative [keybinding management](/components/keys).

## Using UI Components

The [`@semantic-ui/core`](/usage) package provides a collection of essential, pre-built UI components that can be used as a basis to build your website, or other higher-order UI components.
