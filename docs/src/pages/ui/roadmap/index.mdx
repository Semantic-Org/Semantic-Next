## About This Research

> [!note]
> These component lists are based on exhaustive research across 13 major UI frameworks: ShadCN, Chakra UI, Ant Design, Semantic UI Classic, Nuxt UI, Radix UI, MUI (Material-UI), Mantine, HeroUI/NextUI, PrimeReact, Headless UI, Vuetify, Angular Material
> Only components implemented in at least two frameworks are included, ensuring we focus on industry-standard patterns rather than framework-specific solutions.
