## Steps

<Tabs>
  <TabItem label="Javascript">

  1. **Install the package**

      <Tabs>
        <TabItem label="NPM">
          ```bash
          npm install @semantic-ui/core
          ```
        </TabItem>
        <TabItem label="PNPM">
          ```bash
          pnpm install @semantic-ui/core
          ```
        </TabItem>
        <TabItem label="Yarn">
          ```bash
          yarn add @semantic-ui/core
          ```
        </TabItem>
      </Tabs>

  2.  **Import Global CSS Tokens**

      ```javascript
      import '@semantic-ui/core/css';
      ```

  3.  **Import Components**

      *Option 1* - Import the components you would like to use.

      ```javascript
      import { Button } from '@semantic-ui/core';
      ```

      *Option 2* - Import the entire framework to access every component.

      ```javascript
      import '@semantic-ui/core';
      ```

  4. **Use UI Components**

      ```html
      <ui-button primary>Click me</ui-button>
      ```

  </TabItem>
  <TabItem label="Browser">


  1.  **Import Global CSS Tokens from CDN**

      <Code code={cdnCssCode} lang="html" />

  2.  **Import the UI Components from CDN**

      *Option 1* - Import the components you would like to use.

      <Code code={cdnButtonCode} lang="html" />

      *Option 2* - Import the entire framework to access every component.

      <Code code={cdnFullCode} lang="html" />

  3. **Use UI components**

      ```html
      <ui-button primary>Click me</ui-button>
      ```

  </TabItem>
