The DOM Manipulation methods in Query allow you to insert, remove, and modify elements in the DOM. These methods are crucial for creating dynamic and interactive user interfaces in your Semantic UI components.

## append

Insert content to the end of each element in the set of matched elements.

### Syntax
```javascript
$('selector').append(...content)
```

### Parameters
| Name    | Type                | Description                           |
|---------|---------------------|---------------------------------------|
| ...content | string, DOM Element, or Query object | One or more elements to insert |

### Returns
[Query object](/api/query/basic#the-query-object) (for chaining).

### Usage

#### Standard
```javascript
// Append a single element to a div
$('div').append('<p>New content</p>');

// Append multiple elements to a div
$('div').append(
  '<p>First paragraph</p>', 
  '<p>Second paragraph</p>', 
  $('<button>Click me</button>')
);
```

#### Shadow DOM
```javascript
// Append a new button to the action buttons in a user-profile
$$('user-profile').find('.action-buttons').append('<button>Follow</button>');
```

## prepend

Insert content to the beginning of each element in the set of matched elements.

### Syntax
```javascript
$('selector').prepend(...content)
```

### Parameters
| Name    | Type                | Description                           |
|---------|---------------------|---------------------------------------|
| ...content | string, DOM Element, or Query object | One or more elements to insert |

### Returns
[Query object](/api/query/basic#the-query-object) (for chaining).

### Usage

#### Standard
```javascript
// Prepend a single element to a section
$('section').prepend('<h2>New Section Title</h2>');

// Prepend multiple elements to a section
$('section').prepend(
  '<h2>Main Title</h2>', 
  '<div class="subtitle">Subtitle text</div>', 
  $('<hr>')
);
```

#### Shadow DOM
```javascript
// Prepend a notification badge to the user name in a user-profile
$$('user-profile').find('.user-name').prepend('<span class="badge">New</span>');
```

## remove

Remove the set of matched elements from the DOM.

### Syntax
```javascript
$('selector').remove()
```

### Returns
[Query object](/api/query/basic#the-query-object) (for chaining).

### Usage

#### Standard
```javascript
// Remove all paragraphs with a specific class
$('p.outdated').remove();
```

#### Shadow DOM
```javascript
// Remove the offline status indicator from a user-profile
$$('user-profile').find('.status-indicator.offline').remove();
```

## clone

Create a deep copy of the set of matched elements.

### Syntax
```javascript
$('selector').clone()
```

### Returns
A new [Query object](/api/query/basic#the-query-object) containing cloned elements.

### Usage

#### Standard
```javascript
// Clone a template and append it to a container
const $template = $('#item-template').clone();
$('#container').append($template);
```

#### Shadow DOM
```javascript
// Clone a user badge and append it to a list in a user-profile
const $badge = $$('user-profile').find('.user-badge').clone();
$$('user-profile').find('.badge-list').append($badge);
```

## insertBefore

Insert every element in the set of matched elements before the target.

### Syntax
```javascript
$('selector').insertBefore(target)
```

### Parameters
| Name   | Type   | Description                                        |
|--------|--------|----------------------------------------------------|
| target | string | A selector, element, or Query object before which the content will be inserted |

### Returns
[Query object](/api/query/basic#the-query-object) (for chaining).

### Usage

#### Standard
```javascript
// Insert a new paragraph before all existing paragraphs
$('<p>New paragraph</p>').insertBefore('p');
```

#### Shadow DOM
```javascript
// Insert a new header before the user info in a user-profile
$$('<h3>User Details</h3>').insertBefore($$('user-profile').find('.user-info'));
```

### Syntax

### Parameters

|--------|--------|---------------------------------------------------|

## detach

Remove the set of matched elements from the DOM, but keep all associated data and events.

### Syntax
```javascript
$('selector').detach()
```

### Returns
[Query object](/api/query/basic#the-query-object) containing the removed elements.

### Usage

#### Standard
```javascript
// Detach all list items, modify them, and reattach
const $items = $('ul li').detach();
$items.addClass('modified');
$('ul').append($items);
```

#### Shadow DOM
```javascript
// Detach user posts, modify them, and reattach in a user-profile
const $posts = $$('user-profile').find('.user-posts').detach();
$posts.addClass('updated');
$$('user-profile').find('.posts-container').append($posts);
```

### Usage
```javascript
// Reverse the order of list items
$('ul.my-list li').reverse().each((el, index) => {
  console.log(`Reversed order: Item ${index + 1}`);
});
```

## reverse

Reverses the order of the elements in the current set.

### Syntax
```javascript
$('selector').reverse()
```

### Returns
A new [Query object](/api/query/basic#the-query-object) containing the reversed elements.

### Usage
```javascript
// Reverse the order of list items
const $reversed = $('ul li').reverse();
$('ul').empty().append($reversed);
```

## slice

Returns a shallow copy of a portion of the elements into a new Query object.

### Syntax
```javascript
$('selector').slice(start, end)
```

### Parameters
| Name  | Type   | Description                                                                 |
|-------|--------|-----------------------------------------------------------------------------|
| start | number | The beginning index of the specified portion of the collection (optional)  |
| end   | number | The end index of the specified portion of the collection (optional, exclusive) |

### Returns
A new [Query object](/api/query/basic#the-query-object) containing the sliced elements.

### Usage

#### Basic Slicing
```javascript
// Get elements 2-4 from a list of items
const $items = $('.item');
const $sliced = $items.slice(1, 4); // Gets items at index 1, 2, 3

// Get all elements from index 2 onwards
const $fromIndex = $items.slice(2);

// Get the last 2 elements using negative indices
const $lastTwo = $items.slice(-2);
```

#### Working with Multiple Elements
```javascript
// Slice and manipulate a portion of elements
$('.card').slice(0, 3).addClass('featured');

// Process elements in batches
const $allItems = $('.item');
const firstBatch = $allItems.slice(0, 5);
const secondBatch = $allItems.slice(5, 10);

firstBatch.addClass('batch-one');
secondBatch.addClass('batch-two');
```

#### Shadow DOM
```javascript
// Slice user posts in a user-profile component
const $posts = $$('user-profile').find('.user-post');
const $recentPosts = $posts.slice(0, 3);
$recentPosts.addClass('recent');
```

### Notes
- Returns the same instance when called on an empty collection
- Supports negative indices like `Array.prototype.slice`
- Creates a new Query object, enabling method chaining
- Does not modify the original Query object
