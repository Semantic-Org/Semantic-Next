Query is a library built specifically for web components to make it easy to interact with a page's DOM and shadow DOM in a chainable way.

> **Usage Guide** If you are new to Query it is recommended you check out the [user guide](/docs/guides/query/) before reading the API references.

## Installation

Query can be used as a standalone package or alongside templating and other core features.

```bash
npm install @semantic-ui/query
```

## Query Sections

The Query library is organized into several categories:

- **[Basic Usage](/docs/api/query/basic)** - Basic usage of Query and initialization.
- **[Attributes](/docs/api/query/attributes)** - Accessing attributes.
- **[Components](/docs/api/query/components)** - Accessing UI components.
- **[Content](/docs/api/query/content)** - Accessing DOM content.
- **[CSS](/docs/api/query/css)** - Getting and setting CSS values.
- **[Size & Dimensions](/docs/api/query/dimensions)** - Getting and setting width, height, offset and dimensions.
- **[DOM Manipulation](/docs/api/query/dom-manipulation)** - Inserting, removing, or creating DOM content.
- **[DOM Traversal](/docs/api/query/dom-traversal)** - Traversing the DOM to access content.
- **[Events](/docs/api/query/events)** - Binding, triggering and removing events.
- **[Iterators](/docs/api/query/iterators)** - Looping through DOM elements to execute a function, filter, or map.
- **[Logical Operators](/docs/api/query/logical-operators)** - Modifying a query collection using selectors or functions
- **[Utilities](/docs/api/query/utilities)** - Utilities for manipulating the query object
- **[Internal Helpers](/docs/api/query/internal)** - Internal methods used by the Query library
