Navigate the DOM tree relative to matched elements. Use `$$` to pierce shadow DOM boundaries.

## Descendants

### find

```javascript
$('selector').find(selector);
```

Finds descendant elements matching the selector.

#### Parameters

| Name | Type | Description |
|------|------|-------------|
| selector | string | CSS selector to match descendants |

#### Returns

[Query object](/docs/api/query/constructor#the-query-object) containing matched elements.

#### Usage

```javascript
$('div').find('p').addClass('highlight');
```

### closest

```javascript
$('selector').closest(selector);
$('selector').closest(selector, { returnAll: true });
```

Finds the closest ancestor matching the selector. With `returnAll: true`, returns all matching ancestors.

#### Parameters

| Name | Type | Description |
|------|------|-------------|
| selector | string | CSS selector to match ancestors |
| options.returnAll | boolean | Return all matches instead of closest |

#### Returns

[Query object](/docs/api/query/constructor#the-query-object) containing ancestor element(s).

#### Usage

```javascript
$('input').closest('form').submit();
```

#### Example

<PlaygroundExample id="query-closest" direction="horizontal"></PlaygroundExample>

### closestAll

```javascript
$('selector').closestAll(selector);
```

Gets all ancestor elements matching the selector.

> **Alias for** `closest(selector, { returnAll: true })`

#### Parameters

| Name | Type | Description |
|------|------|-------------|
| selector | string | CSS selector to match ancestors |

#### Returns

[Query object](/docs/api/query/constructor#the-query-object) containing all matching ancestors (closest to farthest).

#### Usage

```javascript
$('span').closestAll('.container').addClass('highlight');
```

## Filtering

### filter

```javascript
$('selector').filter(selector);
$('selector').filter(fn);
```

Reduces the set to elements matching the selector or passing the function test.

#### Parameters

| Name | Type | Description |
|------|------|-------------|
| selector | string | CSS selector to match |
| fn | function | Test function, return `true` to include |

#### Returns

[Query object](/docs/api/query/constructor#the-query-object) containing filtered elements.

#### Usage

##### By Selector

```javascript
$('p').filter('.highlight').css('background', 'yellow');
```

##### By Function

```javascript
$('li').filter((el) => $(el).text().includes('important')).addClass('priority');
```

#### Example

<PlaygroundExample id="query-filter" direction="horizontal"></PlaygroundExample>

### not

```javascript
$('selector').not(selector);
$('selector').not(fn);
```

Removes elements matching the selector or passing the function test.

#### Parameters

| Name | Type | Description |
|------|------|-------------|
| selector | string | CSS selector to exclude |
| fn | function | Test function, return `true` to exclude |

#### Returns

[Query object](/docs/api/query/constructor#the-query-object) containing remaining elements.

#### Usage

##### By Selector

```javascript
$('p').not('.exclude').css('color', 'blue');
```

##### By Function

```javascript
$('li').not((el) => $(el).text().trim() === '').addClass('visible');
```

#### Example

<PlaygroundExample id="query-not" direction="horizontal"></PlaygroundExample>

### is

```javascript
$('selector').is(selector);
$('selector').is(fn);
```

Tests if any element matches the selector or passes the function test.

#### Parameters

| Name | Type | Description |
|------|------|-------------|
| selector | string | CSS selector to test |
| fn | function | Test function |

#### Returns

`true` if at least one element matches, `false` otherwise.

#### Usage

```javascript
if ($('p').is('.active')) {
  console.log('At least one paragraph is active');
}
```

#### Example

<PlaygroundExample id="query-is" direction="horizontal"></PlaygroundExample>

### contains

```javascript
$('selector').contains(element);
```

Tests if the first matched element contains the given element.

#### Parameters

| Name | Type | Description |
|------|------|-------------|
| element | Element | Element to check for |

#### Returns

`true` if contained, `false` otherwise.

#### Usage

```javascript
if ($('#container').contains(event.target)) {
  console.log('Click was inside container');
}
```

## Chain

### end

```javascript
$('selector').find('child').end();
```

Returns to the previous Query set in the chain.

#### Returns

[Query object](/docs/api/query/constructor#the-query-object) before the last traversal.

#### Usage

```javascript
$('.card')
  .find('.title').css('font-weight', 'bold').end()
  .find('.content').html('<p>New</p>');
```
