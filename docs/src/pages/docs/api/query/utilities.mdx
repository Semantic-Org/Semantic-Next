Utility methods for working with Query collections and element access.

## Collection Info

### count

```javascript
$('selector').count()
```

Gets the number of elements in the Query object.

#### Returns

Number of elements.

#### Example

<PlaygroundExample id="query-count" direction="horizontal"></PlaygroundExample>

### index

```javascript
$('selector').index()
```

Gets the index of the first element relative to its siblings.

#### Returns

Index position, or `-1` if not found.

### exists

```javascript
$('selector').exists()
```

Checks if there are any elements in the Query object.

#### Returns

`true` if at least one element exists, `false` otherwise.

#### Example

<PlaygroundExample id="query-exists" direction="horizontal"></PlaygroundExample>

## Element Access

### el

```javascript
$('selector').el()
```

Returns the first DOM element in the collection.

#### Returns

First DOM element, or `undefined` if empty.

#### Example

<PlaygroundExample id="query-el" direction="horizontal"></PlaygroundExample>

### get

```javascript
$('selector').get()
$('selector').get(index)
```

Gets the DOM element at the specified index, or all elements as an array.

#### Parameters

| Name  | Type   | Description                       |
|-------|--------|-----------------------------------|
| index | number | Index of element to retrieve      |

#### Returns

Element at index, array of all elements, or `undefined` if out of bounds.

### eq

```javascript
$('selector').eq(index)
```

Returns a new Query instance containing the element at the specified index.

#### Parameters

| Name  | Type   | Description                    |
|-------|--------|--------------------------------|
| index | number | Index of element to retrieve   |

#### Returns

New Query instance with the element.

### first

```javascript
$('selector').first()
```

Returns a new Query instance containing the first element.

#### Returns

New Query instance with the first element.

### last

```javascript
$('selector').last()
```

Returns a new Query instance containing the last element.

#### Returns

New Query instance with the last element.

## Properties

### prop

```javascript
$('selector').prop(name)
$('selector').prop(name, value)
```

Gets or sets a property on elements.

#### Parameters

| Name  | Type   | Description              |
|-------|--------|--------------------------|
| name  | string | Property name            |
| value | any    | Value to set             |

#### Returns

Property value when getting, Query object when setting.

## Collection Manipulation

### reverse

```javascript
$('selector').reverse()
```

Reverses the order of elements in the collection.

#### Returns

New Query object with reversed elements.

### slice

```javascript
$('selector').slice(start, end)
```

Returns a shallow copy of a portion of elements.

#### Parameters

| Name  | Type   | Description                              |
|-------|--------|------------------------------------------|
| start | number | Beginning index (optional)               |
| end   | number | End index, exclusive (optional)          |

#### Returns

New Query object with sliced elements.

#### Example

<PlaygroundExample id="query-slice" direction="horizontal"></PlaygroundExample>

### add

```javascript
$('selector').add(selector)
```

Creates a new Query collection combining current elements with additional elements.

#### Parameters

| Name     | Type                                    | Description                    |
|----------|-----------------------------------------|--------------------------------|
| selector | string/Element/NodeList/Query           | Elements to add                |

#### Returns

New Query object with combined elements (duplicates removed).

#### Example

<PlaygroundExample id="query-add" direction="horizontal"></PlaygroundExample>
