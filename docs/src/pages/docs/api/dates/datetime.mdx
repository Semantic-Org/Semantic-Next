An exact moment with a zone to read it in, one type for timestamps, appointments and deadlines. The class is `DateTime`, a `Temporal.ZonedDateTime` underneath.

## Creating

### datetime

```javascript
datetime(input);
datetime(input, zone);
datetime(input, { zone, loose, dayFirst });
```

Reads an ISO string, a `Date`, epoch milliseconds, a fields object, a date, or a Temporal value. A missing value refuses, `now()` reads the current moment.

#### Parameters

| Name | Type | Description |
|------|------|-------------|
| input | string \| Date \| number \| object \| CalendarDate \| Temporal | `'2026-09-06T14:30Z'` as an instant, `'2026-09-06T14:30'` as a wall clock in the zone, `'2026-09-06'` as midnight, a `Date`, epoch milliseconds, `{ year, month, day, hour }`, a date at its midnight, or a Temporal value |
| zone | string | The zone to read in, else a bracketed zone in the string, else the configured default, else the machine's |
| options | object | `{ zone, loose, dayFirst }`. See [Reading Values](/docs/api/dates/reading-values) |

#### Returns

A `DateTime`, or `null` under `{ loose: true }` for input that cannot be read.

#### Usage

```javascript
datetime('2026-09-06T14:30Z', 'America/New_York').format('long'); // 'September 6, 2026 at 10:30 AM'
datetime('2026-09-06T14:30', 'Asia/Tokyo').toString(); // '2026-09-06T05:30:00.000Z'
datetime('2026-09-06', 'UTC').toString(); // '2026-09-06T00:00:00.000Z'
datetime('2026-09-06T14:30:00+09:00[Asia/Tokyo]').zone; // 'Asia/Tokyo'
datetime(0, 'UTC').toString(); // '1970-01-01T00:00:00.000Z'
datetime({ year: 2026, month: 9, day: 6, hour: 9 }, 'UTC').toString(); // '2026-09-06T09:00:00.000Z'
```

### now

```javascript
now();
now(zone);
```

The current moment at millisecond precision, in the zone or the configured default.

#### Parameters

| Name | Type | Description |
|------|------|-------------|
| zone | string | The zone to read in |

#### Returns

A `DateTime`.

#### Usage


## Properties

The parts are real properties, so a value prints them in a console without a click. Every property is read-only.

| Name | Type | Description |
|------|------|-------------|
| year | number | |
| month | number | 1 through 12 |
| day | number | |
| weekday | number | ISO, 1 for monday through 7 for sunday |
| hour | number | |
| minute | number | |
| second | number | |
| millisecond | number | |
| microsecond | number | |
| nanosecond | number | |
| zone | string | The canonical zone id, `'America/New_York'` |
| offset | string | The UTC offset in effect, `'-04:00'` |
| epoch | number | Epoch milliseconds |
| quarter | number | 1 through 4 |
| dayOfYear | number | |
| weekOfYear | number | ISO week number |
| daysInMonth | number | |
| daysInYear | number | |
| hoursInDay | number | 23, 24 or 25 across a daylight saving change |
| date | CalendarDate | The calendar date in this zone |
| time | Time | The time of day in this zone |

#### Usage

```javascript
const moment = datetime('2026-09-06T14:30:15.250', 'America/New_York');

moment.year; // 2026
moment.weekday; // 7
moment.zone; // 'America/New_York'
moment.offset; // '-04:00'
moment.epoch; // 1788719415250
moment.date.toString(); // '2026-09-06'
moment.time.toString(); // '14:30:15.250'
```

## Moving

### plus

```javascript
datetime.plus(duration);
datetime.plus(fields);
datetime.plus(phrase);
datetime.plus(count, unit);
```

Adds a duration. Adding days keeps the wall clock across a daylight saving change, adding hours counts hours.

#### Parameters

| Name | Type | Description |
|------|------|-------------|
| amount | Duration \| object \| string \| number | A duration, a fields object like `{ days: 3 }`, a phrase like `'1h 30m'`, or a count with a unit. A count written as text reads as its number |
| unit | string | The unit for a count, `'days'`, `'hours'`, `'weeks'` |

#### Returns

A new `DateTime`.

#### Usage

```javascript
const moment = datetime('2026-09-06T14:30', 'UTC');

moment.plus(days(3)).toString(); // '2026-09-09T14:30:00.000Z'
moment.plus({ hours: 1, minutes: 30 }).toString(); // '2026-09-06T16:00:00.000Z'
moment.plus('1h 30m').toString(); // '2026-09-06T16:00:00.000Z'
moment.plus(2, 'weeks').toString(); // '2026-09-20T14:30:00.000Z'

const friday = datetime('2026-03-06T17:00', 'America/New_York');
friday.plus(days(3)).format('dddd h:mm a'); // 'Monday 5:00 pm'
friday.plus(hours(72)).format('dddd h:mm a'); // 'Monday 6:00 pm'
```

### set

```javascript
datetime.set(fields);
datetime.set(unit, value);
```

Replaces parts. A part out of range refuses with `cannotSet` rather than rolling over, the way the factory refuses one.

#### Parameters

| Name | Type | Description |
|------|------|-------------|
| fields | object | Singular keys, `{ hour: 9, minute: 0 }` |
| unit | string | One part to replace, `'year'`, `'hour'` |
| value | number | Its new value |

#### Returns

A new `DateTime`.

#### Usage

```javascript
const moment = datetime('2026-09-06T14:30', 'UTC');

moment.set({ hour: 9, minute: 0 }).toString(); // '2026-09-06T09:00:00.000Z'
moment.set('year', 2030).toString(); // '2030-09-06T14:30:00.000Z'
```

## Measuring

### until

```javascript
datetime.until(other);
datetime.until(other, unit);
```

The duration from this moment to another, balanced from years down, or the whole length as a number in one unit. The duration remembers this moment, so its months and years total. See [Durations](/docs/api/dates/durations#anchors).

#### Parameters

| Name | Type | Description |
|------|------|-------------|
| other | DateTime \| string \| Date \| number | Anything `datetime()` reads |
| unit | string | A unit to total in, `'hours'`, `'days'`, `'months'` |

#### Returns

A `Duration`, or a number with a unit. Negative when `other` comes first.

#### Usage

```javascript
const start = datetime('2026-01-01T00:00Z', 'UTC');
const end = datetime('2026-04-05T06:07Z', 'UTC');

start.until(end).toString(); // 'P3M4DT6H7M'
start.until(end).format(); // '3 months, 4 days, 6 hours, 7 minutes'
start.until(end, 'hours'); // 2262.116666666667
end.until(start).toString(); // '-P3M4DT6H7M'
```

<PlaygroundExample id="dates-datetime-until" direction="horizontal"></PlaygroundExample>

## Ranges

### to

```javascript
datetime.to(end);
datetime.to(duration);
datetime.to(count, unit);
```

A range from this moment until another, or covering a length, the end excluded. See [Range Bounds](/docs/api/dates/range-bounds).

#### Parameters

| Name | Type | Description |
|------|------|-------------|
| end | DateTime \| string \| Date \| number \| Duration \| object | Another moment, read in this zone, or a length as a duration, fields or phrase |
| count | number | A count with a unit |
| unit | string | The unit for a count |

#### Returns

A `DateTimeRange`.

#### Usage

```javascript

start.to(90, 'minutes').toString(); // '2026-09-06T09:00:00.000Z/2026-09-06T10:30:00.000Z'
```

| Name | Type | Description |
|------|------|-------------|
| unit | string | `'year'`, `'quarter'`, `'month'`, `'week'`, `'day'`, `'hour'` |
| firstDay | string \| number | The weekday a week starts on, for `'week'` |

#### Returns

A `DateTimeRange`.

#### Usage

```javascript
const moment = datetime('2026-09-06T14:30', 'UTC');

moment.range('day').toString(); // '2026-09-06T00:00:00.000Z/2026-09-07T00:00:00.000Z'
moment.range('month').toString(); // '2026-09-01T00:00:00.000Z/2026-10-01T00:00:00.000Z'
moment.range('day').contains('2026-09-07T00:00Z'); // false
```

## Formatting

### format

```javascript
datetime.format();
datetime.format(preset);
datetime.format(options);
datetime.format(tokens);
datetime.format(spec, locale);
```

Prints in the configured locale or one given. No argument is the locale's medium date and short time.

#### Parameters

| Name | Type | Description |
|------|------|-------------|
| spec | string \| object | A preset, an `Intl.DateTimeFormat` options object, or a day.js token pattern |
| locale | string | A BCP 47 tag for this call, `'de'`, `'fr-FR'` |

##### Presets

| Preset | Prints |
|--------|--------|
| `'short'` | `9/6/26, 2:30 PM` |
| `'medium'` | `Sep 6, 2026, 2:30 PM`, the default |
| `'long'` | `September 6, 2026 at 2:30 PM` |
| `'full'` | `Sunday, September 6, 2026 at 2:30 PM` |
| `'date'` | `Sep 6, 2026` |
| `'time'` | `2:30 PM` |
| `'month'` | `September 2026` |

##### Tokens

| Token | Prints | Token | Prints |
|-------|--------|-------|--------|
| `YYYY` `YY` | `2026` `26` | `HH` `H` | `14` `14` |
| `MMMM` `MMM` `MM` `M` | `September` `Sep` `09` `9` | `hh` `h` | `02` `2` |
| `DD` `D` `Do` | `06` `6` `6th` | `mm` `m` | `30` `30` |
| `dddd` `ddd` `dd` | `Sunday` `Sun` `Su` | `ss` `s` `SSS` | `00` `0` `000` |
| `Q` `W` | `3` `36` | `A` `a` | `PM` `pm` |
| `X` `x` | epoch seconds, epoch milliseconds | `Z` `ZZ` | `+00:00` `+0000` |
| `[text]` | passes through | `z` `zzzz` | `UTC` `Coordinated Universal Time` |

The presets stand in for day.js's `L` and `LLL`. An Intl options object may name its own `timeZone`.

#### Returns

A string.

#### Usage

```javascript
const moment = datetime('2026-09-06T14:30', 'UTC');

moment.format(); // 'Sep 6, 2026, 2:30 PM'
moment.format('long'); // 'September 6, 2026 at 2:30 PM'
moment.format({ weekday: 'long', hour: 'numeric' }); // 'Sunday 2 PM'
moment.format({ timeStyle: 'short', timeZone: 'Asia/Tokyo' }); // '11:30 PM'
moment.format('dddd, MMMM Do YYYY [at] h:mm a'); // 'Sunday, September 6th 2026 at 2:30 pm'
moment.format('long', 'fr-FR'); // '6 septembre 2026 à 14:30'
```

## Converting

### toString

```javascript
datetime.toString();
```

The instant in UTC, `'2026-09-06T14:30:00.000Z'`, so two clients storing the same moment store the same bytes. Six or nine fraction digits print only when the value has them.

#### Returns

A string.

#### Usage

```javascript

```

### valueOf

```javascript
datetime.valueOf();
```

Epoch milliseconds, so datetimes sort with `(a, b) => a - b` and compare with `<`, while `'Due ' + dt` gives the string, as `Date` decides it. A date, a time and a range refuse `valueOf`. See [the rules](/docs/api/dates#the-rules).

#### Returns

A number.

#### Usage

```javascript
const later = datetime('2026-09-06T14:35Z');
const earlier = datetime('2026-09-06T14:30Z');

later - earlier; // 300000
later > earlier; // true
[later, earlier].sort((a, b) => a - b)[0] === earlier; // true
```
