`@semantic-ui/reactivity` is a standalone implementation of a signals based reactivity system. It is used internally to power templating and rendering components, but can also be used as reactivity primitives for any custom project.

## Installation

Reactivity can be used as a standalone package or alongside [Semantic UI components](/docs/guides/components).

```bash
npm install @semantic-ui/reactivity
```

## Basic Usage

```javascript
import { signal, reaction } from '@semantic-ui/reactivity';

const counter = signal(0);

reaction(() => {
  console.log('Counter value:', counter.get());
});

counter.set(1); // Console: "Counter value: 1"
```

* **[Signal](/docs/api/reactivity/signal)** - Create reactive values

* **[Derived Signals](/docs/api/reactivity/derived-signals)** - Compute signals from other signals

* **[Scheduler](/docs/api/reactivity/scheduler)** - The batching engine
* **[Dependency](/docs/api/reactivity/dependency)** - Low-level dependency tracking

## Reactive Helpers

Semantic UI includes various helpers to make it easy to manipulate data like arrays, records (arrays of objects), counters, toggles, and streamline data manipulation.

* **[Number Helpers](/docs/api/reactivity/number-helpers)**
  - [`increment(amount)`](/docs/api/reactivity/number-helpers#increment)
  - [`decrement(amount)`](/docs/api/reactivity/number-helpers#decrement)

* **[Boolean Helpers](/docs/api/reactivity/boolean-helpers)**
  - [`toggle()`](/docs/api/reactivity/boolean-helpers#toggle) for toggling between `false` and `true`

* **[Array Helpers](/docs/api/reactivity/array-helpers)**
  - [`push()`](/docs/api/reactivity/array-helpers#push)
  - [`unshift()`](/docs/api/reactivity/array-helpers#unshift)
  - [`splice()`](/docs/api/reactivity/array-helpers#splice)
  - [`setIndex(index, value)`](/docs/api/reactivity/array-helpers#setindex)
  - [`removeIndex(index)`](/docs/api/reactivity/array-helpers#removeindex)
  - [`setArrayProperty(indexOrProp, property, value)`](/docs/api/reactivity/array-helpers#setarrayproperty)

* **[Collection Helpers](/docs/api/reactivity/collection-helpers)** (Array of Objects)
  - [`setProperty(id, property, value)`](/docs/api/reactivity/collection-helpers#setproperty)
  - [`replaceItem(item, id)`](/docs/api/reactivity/collection-helpers#replaceitem)
  - [`removeItem(id)`](/docs/api/reactivity/collection-helpers#removeitem)
  - [`getIndex(id)`](/docs/api/reactivity/collection-helpers#getindex)
  - [`getId(item)`](/docs/api/reactivity/collection-helpers#getid)
  - [`hasId(item)`](/docs/api/reactivity/collection-helpers#hasid)

* **[Date Helpers](/docs/api/reactivity/date-helpers)**
  - [`now()`](/docs/api/reactivity/date-helpers#now) for setting to current time

These helpers provide convenient ways to manipulate reactive data structures and streamline common operations in your reactive computations.
