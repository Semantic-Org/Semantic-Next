Look up, update, and remove objects in an array signal by identity. Each item is matched by its id, resolved through the signal's [`id`](/docs/api/reactivity/signal#signal) option, which defaults to the first present of `id`, `_id`, `hash`, or `key`.

> [!info]
> The collection helpers match by resolved id, not by position. Reordering the array does not change which item a given id points to. Pass a custom `id` resolver to `signal()` when your items key on a different field.

## Identity

### getId

```javascript
signal.getId(item);
```

Resolves an item's id through the signal's `id` resolver. A primitive item is its own id.

#### Parameters

| Name | Type | Description |
|------|------|-------------|
| item | object \| primitive | The item to read an id from |

#### Returns

The resolved id, or `undefined` if none is present.

#### Usage

```javascript
const users = signal([{ id: 'u1', name: 'Alice' }]);

users.getId(users.peek()[0]); // 'u1'
users.getId('u1');            // 'u1' — a primitive is its own id
```

### getIds

```javascript
signal.getIds(item);
```

Returns every id value present on an object, in `id`, `_id`, `hash`, `key` order. Unlike `getId`, this ignores the signal's resolver and reports all candidate keys.

#### Parameters

| Name | Type | Description |
|------|------|-------------|
| item | object \| primitive | The item to read ids from |

#### Returns

An array of the id values found. A primitive returns a single-element array of itself.

#### Usage

```javascript
const users = signal([{ _id: '1', id: 'u1', name: 'Alice' }]);

users.getIds(users.peek()[0]); // ['u1', '1']
```

### hasId

```javascript
signal.hasId(item, id);
```

Reports whether an item resolves to the given id.

#### Parameters

| Name | Type | Description |
|------|------|-------------|
| item | object \| primitive | The item to test |
| id | string | The id to match against |

#### Returns

`true` if the item's resolved id matches `id`.

## Lookup

### getItem

```javascript
signal.getItem(id);
```

Returns the item in the array matching `id`. Subscribes the running reaction through the underlying read.

#### Parameters

| Name | Type | Description |
|------|------|-------------|
| id | string | The id to look for |

#### Returns

The matching item, or `undefined` if none matches.

### getItemIndex

```javascript
signal.getItemIndex(id);
```

Returns the array index of the item matching `id`.

#### Parameters

| Name | Type | Description |
|------|------|-------------|
| id | string | The id to look for |

#### Returns

The index of the matching item, or `-1` if none matches.

## Mutation

### setProperty

```javascript
signal.setProperty(id, property, value);
```

Sets a single property on the item matching `id`, notifying dependents only when the value changes.

#### Parameters

| Name | Type | Description |
|------|------|-------------|
| id | string | The id of the item to modify |
| property | string | The property to set |
| value | any | The value to assign |

#### Usage

```javascript
const users = signal([
  { id: 'u1', name: 'Alice' },
  { id: 'u2', name: 'Bob' },
]);

users.setProperty('u1', 'status', 'active');
```

##### On a plain object

When the signal holds a single object rather than an array, the id argument drops and `setProperty` takes `(property, value)`.

```javascript
const profile = signal({ name: 'Alice', status: 'idle' });

profile.setProperty('status', 'active');
```

### replaceItem

```javascript
signal.replaceItem(id, item);
```

Swaps the item matching `id` for a new one. No-ops if no item matches.

#### Parameters

| Name | Type | Description |
|------|------|-------------|
| id | string | The id of the item to replace |
| item | object | The replacement item |

#### Usage

```javascript
const users = signal([
  { id: 'u1', name: 'Alice' },
  { id: 'u2', name: 'Bob' },
]);

users.replaceItem('u1', { id: 'u1', name: 'Alex' });
```

### removeItem

```javascript
signal.removeItem(id);
```

Removes the item matching `id` from the array. No-ops if no item matches.

#### Parameters

| Name | Type | Description |
|------|------|-------------|
| id | string | The id of the item to remove |

#### Usage

```javascript
const users = signal([
  { id: 'u1', name: 'Alice' },
  { id: 'u2', name: 'Bob' },
]);

users.removeItem('u1');
```

## Batch

### setArrayProperty

```javascript
signal.setArrayProperty(index, property, value);
signal.setArrayProperty(property, value);
```

Sets a property on one item by index, or on every item when the index is omitted. Notifies once if any value changed.

> [!note]
> `setArrayProperty` keys by index rather than id and predates the identity-based helpers above. Prefer `setProperty` for single-item updates. The batch form is slated for a future redesign.
