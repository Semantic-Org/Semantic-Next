Semantic UI provides packages for authoring **standard W3C [Web Components](https://developer.mozilla.org/en-US/docs/Web/API/Web_components)** using the same underlying technologies built to create the [first-party UI component framework](/framework).

Web components can be used anywhere you write html, work natively in modern browsers and have first-class support with frameworks like [React](https://react.dev/), [Vue](https://vuejs.org/), and [Angular](https://angular.io/) which means you can **create your UI once and use it anywhere you ship websites**.

### Key Features

*   [Signals-based reactivity](/docs/guides/reactivity) for state management.
*   [Declarative templating](/docs/guides/templates) for rendering component views.
*   [DOM querying](/docs/guides/query) tailored for [Shadow DOM](https://developer.mozilla.org/en-US/docs/Web/API/Web_components/Using_shadow_DOM) encapsulation.
*   CSS token framework for [dark/light mode styling and theming](/docs/guides/components/styling).
*   Integrated [event handling](/docs/guides/components/events) tools.
*   Declarative [keybinding management](/docs/guides/components/keys).

> To see examples of custom components check out our [examples gallery](/examples/advanced-ball-simulation).
