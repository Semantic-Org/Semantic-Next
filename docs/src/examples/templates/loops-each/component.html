Basic each with array from state

    {#each numbers}
  • {this}
    • {/each}

Each with inline array

    {#each [1, 2, 3]}
  • {this}
    • {/each}

Each with mixed expressions

    {#each [getFirst, getSecond, 3]}
  • {this}
    • {/each}

Each with objects (direct property access)

    {#each people}
  • {name} - {age}
    • {/each}
