## State and Reactivity

Reactivity is the heart of Semantic UI components. This lesson introduces you to reactive state management using signals - automatically updating your UI when data changes.

## Understanding State

The [`defaultState`](/components/state#declaring-state) object defines your component's reactive properties. When these values change, your template automatically updates to reflect the new data.

## Reactive Properties

Looking at [component.js](#component.js), you'll notice:

- `defaultState` initializes a counter and toggle property
- We use [`.set()`](/components/state#updating-state) to update values in event handlers
- We use [`.get()`](/components/state#accessing-state) to access values in JavaScript code
- The template updates automatically when state changes

## State Operators

The framework provides special methods for common state operations:

- [`.increment()`](/reactivity/variables#number-methods) and `.decrement()` for numbers
- [`.toggle()`](/reactivity/variables#boolean-methods) for booleans
- [`.now()`](/reactivity/variables#date-methods) for dates (updates to current time)
- Array methods like [`.push()`](/reactivity/variables#array-methods), `.pop()`, `.remove()`

## Template Access

In the [component.html](#component.html) template:

- State is accessed [directly without using `.get()`](/components/state#in-templates): `{count}`
- The UI automatically updates when state changes
- Methods can be called from templates: `{isEven(count)}`

Enhance the counter component to include:

2. A "step" feature that increments by a configurable amount
3. Visual indicators when reaching milestone numbers (like 10, 20, etc.)
