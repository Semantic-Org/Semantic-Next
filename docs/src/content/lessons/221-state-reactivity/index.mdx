## State and Reactivity

Reactivity is the heart of Semantic UI components. This lesson introduces you to reactive state management using signals - automatically updating your UI when data changes.

## Understanding State

The [`defaultState`](/docs/guides/components/state#declaring-state) object defines your component's reactive properties. When these values change, your template automatically updates to reflect the new data.

## Reactive Properties

Looking at [component.js](#component.js), you'll notice:

- `defaultState` initializes a counter and toggle property
- We use [`.set()`](/docs/guides/components/state#updating-state) to update values in event handlers
- We use [`.get()`](/docs/guides/components/state#accessing-state) to access values in JavaScript code
- The template updates automatically when state changes

## State Operators

The framework provides special methods for common state operations:

- [`.increment()`](/docs/api/reactivity/number-helpers#increment) and [`.decrement()`](/docs/api/reactivity/number-helpers#decrement) for numbers
- [`.toggle()`](/docs/api/reactivity/boolean-helpers#toggle) for booleans
- [`.now()`](/docs/api/reactivity/date-helpers#now) for dates (updates to current time)
- Array methods like [`.push()`](/docs/api/reactivity/array-helpers#push), [`.removeIndex()`](/docs/api/reactivity/array-helpers#removeindex), [`.setIndex()`](/docs/api/reactivity/array-helpers#setindex)

## Template Access

In the [component.html](#component.html) template:

- State is accessed [directly without using `.get()`](/docs/guides/components/state#in-templates): `{count}`
- The UI automatically updates when state changes
- Methods can be called from templates: `{isEven(count)}`

## Try It Yourself

Enhance the counter component to include:

1. A reset button that sets the counter back to zero
2. A "step" feature that increments by a configurable amount
3. Visual indicators when reaching milestone numbers (like 10, 20, etc.)

Hint: You'll need to add a new state property and method, and update the template to use them.
