### Your First Web Component in Seconds

Web components don't have to be complex. Look at the example to see a complete component that updates every second.

**That's it.** You now have a `<live-clock>` element that works in any HTML page.

### What Just Happened?

- **`tagName`**: Creates a new HTML element `<live-clock>`
- **`template`**: What gets rendered (updates automatically when data changes)  
- **`defaultState`**: Reactive data that triggers re-renders
- **`onCreated()`**: Runs when the component starts up

### Web Standards, Not Framework Magic

This isn't framework-specific syntax - it's built on web standards. Your `<live-clock>` element works everywhere:

```html
<!-- Works in any HTML -->
<live-clock></live-clock>

<!-- Works in React -->
<live-clock />

<!-- Works in Vue -->
<live-clock></live-clock>
```
