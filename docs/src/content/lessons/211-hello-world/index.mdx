## Hello World Component

This lesson introduces your first Semantic UI web component. We'll create a simple real-time clock that updates every second. You'll learn the basics of component definition, templates, and reactivity.

## Key Concepts

1. **Component Definition**: The [`defineComponent`](/components/create#defining-components) function creates a web component with a specified tag name.

2. **Template**: The template contains HTML with [expressions](/templates/expressions) in curly braces `{}` that display reactive data.

3. **State**: The [`defaultState`](/components/state#declaring-state) object defines reactive properties that automatically update the UI when changed.

4. **Lifecycle**: The [`onCreated`](/components/lifecycle) function runs when the component is initialized, perfect for setup code.

5. **Reactivity**: Using [`state.time.now()`](/api/reactivity/date-helpers#now) updates the time and automatically refreshes the display.

## Understanding the Code

Looking at [component.js](#component.js), notice how:

- We import `defineComponent` from the framework
- The `tagName` property specifies the HTML element name
- The template uses [`{formatDate time "h:mm:ss a"}`](/templates/expressions#format-date) to display formatted time
- `defaultState` initializes our reactive data
- `onCreated` sets up a timer that updates every second

## Using the Component

Once defined, you can use your component in HTML as shown in [page.html](#page.html). No additional setup is required!
