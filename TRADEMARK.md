# Semantic UI Trademark Policy

"Semantic UI" is a registered trademark of Jack Lukic.

This policy explains how you may use the Semantic UI name and brand in relation to this open source project. The source code is freely available under its license, but the name and brand are not.

## Allowed

- Saying your project is "built with Semantic UI" or "compatible with Semantic UI"
- Referring to Semantic UI in blog posts, talks, tutorials, and documentation
- Using the name to accurately describe this project in conversation

## Not Allowed

- Using "Semantic UI" (or confusingly similar names) as the name of a fork, derivative, or competing project
- Implying official endorsement, affiliation, or sponsorship without written permission
- Using the Semantic UI logo or brand assets in your own project's branding
- Distributing a modified version of this software under the "Semantic UI" name

## Forks

You are free to fork this project under its open source license. Forks **must** use a distinctly different name and branding that does not suggest they are Semantic UI or an official variant of it.

## Questions

If you're unsure whether your use qualifies, open an issue or contact the maintainers before proceeding.
