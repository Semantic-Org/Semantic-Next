cdn.semantic-ui.com / fonts

Font Sets

canary

Self-hosted web fonts served as CSS with woff2 references. Lato is loaded by default when using components. Suppress with fonts="none".

Usage

Via loader (automatic)
<!-- Lato is auto-included with components -->
<script src="https://cdn.semantic-ui.com/load" version="canary" components></script>

<!-- Suppress font loading -->
<script src="https://cdn.semantic-ui.com/load" version="canary" components
  fonts="none"
></script>
Direct link
<link rel="stylesheet" href="https://cdn.semantic-ui.com/fonts/lato">
Preload (optional)
<link rel="preload" as="font" type="font/woff2" crossorigin
  href="https://cdn.semantic-ui.com/fonts@canary/lato/LatoLatin-Regular.woff2"
>

The crossorigin attribute is required when preloading font files directly.
