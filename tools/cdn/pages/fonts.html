Font Sets

Self-hosted web fonts served as CSS with woff2 references. Lato is loaded by default with components. Suppress with fonts="none".

Usage

Via Loader

Lato is auto-included with components. Suppress with fonts="none".

<!-- Lato is auto-included with components -->
<script src="https://cdn.semantic-ui.com/load" components></script>

<!-- Suppress font loading -->
<script src="https://cdn.semantic-ui.com/load" components
  fonts="none"
></script>

Direct Link

Link the font CSS directly without the loader.

<link rel="stylesheet" href="https://cdn.semantic-ui.com/fonts/lato">

Preload

Preload the font file for faster rendering. The crossorigin attribute is required.

<link rel="preload" as="font" type="font/woff2" crossorigin
  href="https://cdn.semantic-ui.com/fonts@canary/lato/LatoLatin-Regular.woff2"
>
