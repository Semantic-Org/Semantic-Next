Icon Sets

Self-hosted icon libraries served as CSS with SVG mask references. Lucide is loaded by default with components. Switch sets via the loader or link directly.

Available Sets

brands/icons/brandsBrand logos and framework icons. Multi-color.

Usage

Via Loader

Lucide is auto-included with components. Override with the icons attribute.

<!-- Default: Lucide is auto-included -->
<script src="https://cdn.semantic-ui.com/load" components></script>

<!-- Override to a different set -->
<script src="https://cdn.semantic-ui.com/load" components
  icons="phosphor"
></script>
<!-- Combine multiple sets -->
<script src="https://cdn.semantic-ui.com/load" components
  icons="lucide,brands"
></script>

Direct Link

Link the CSS directly without the loader.

<link rel="stylesheet" href="https://cdn.semantic-ui.com/icons/lucide">

Canonical names: All icon sets use Semantic UI's canonical naming. The same name (e.g. home) resolves across all sets, so you can switch sets without changing markup.
