cdn.semantic-ui.com / icons

Icon Sets

canary

Self-hosted icon libraries served as CSS with SVG references. Lucide is loaded by default when using components. Switch sets via the loader or link directly.

Available Sets

lucide
Clean, consistent stroke icons. Default set.
/icons/lucide
phosphor
Flexible icons in multiple weights.
/icons/phosphor
tabler
Over 5000 free MIT-licensed icons.
/icons/tabler
material-symbols
Google's Material Design icon set.
/icons/material-symbols
heroicons
Hand-crafted icons by the Tailwind team.
/icons/heroicons
brands
Brand logos and framework icons. Multi-color.
/icons/brands

Usage

Via loader (recommended)
<!-- Default: Lucide is auto-included with components -->
<script src="https://cdn.semantic-ui.com/load" version="canary" components="icon"></script>

<!-- Override to a different set -->
<script src="https://cdn.semantic-ui.com/load" version="canary" components="icon"
  icons="phosphor"
></script>

<!-- Combine multiple sets -->
<script src="https://cdn.semantic-ui.com/load" version="canary" components="icon"
  icons="lucide,brands"
></script>
Direct link
<link rel="stylesheet" href="https://cdn.semantic-ui.com/icons/lucide">
Canonical names: All icon sets use Semantic UI's canonical naming. The same name (e.g. home) resolves across all sets, so you can switch sets without changing markup.
